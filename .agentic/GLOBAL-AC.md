# Global Acceptance Criteria

Defines system-wide done-ness checks.

**Purpose:**
A checklist that must be satisfied before any major task is marked complete in `TASKS.md`.

## Core Criteria
- Code changes must not break existing functionality.
- Any new features must be documented.
- Scratchpad scripts must be placed in `agent_scripts/`.
- If an architectural decision was made, it must be logged in `MEMORY.md`.
- Handoff notes must be written to `.agentic/HANDOFFS/` to inform the next role in the sequence.
